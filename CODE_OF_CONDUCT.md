# Code of conduct

We are committed to a respectful, harassment-free community. Be constructive, assume good faith while reviewing ideas, criticize code rather than people, respect privacy, and avoid discriminatory or sexualized language and conduct.

Maintainers may edit or remove contributions and restrict participation when behavior threatens a safe, productive project. Report conduct concerns privately to the repository maintainers. Enforcement should be proportionate, documented, and protect reporter confidentiality.
