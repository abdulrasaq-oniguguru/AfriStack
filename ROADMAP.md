# Roadmap

## v0.1 — Nigeria payment foundation

- [x] Canonical payments, errors, money, registry, and secret-provider contracts
- [x] Stateful local mock with idempotent create and signed events
- [x] Paystack and Flutterwave HTTP adapters with deterministic tests
- [x] Current provider webhook signature verification and normalization
- [ ] Project-owned sandbox certification
- [ ] Fastify gateway, PostgreSQL idempotency, API keys, durable webhook inbox, OpenAPI
- [ ] Docker Compose mock quickstart
- [ ] CLI init/doctor/providers/capabilities/test/dev
- [ ] Node/Express, Next.js, and Django examples
- [ ] Termii, then Africa's Talking messaging

## Expansion

Kenya and Ghana follow only after v0.1 reliability. M-Pesa and MTN MoMo receive dedicated asynchronous collection/disbursement contracts. Uganda, Tanzania, Rwanda, and South Africa follow verified community contributions. Identity and offline sync remain separate reviewed milestones.
