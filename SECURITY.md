# Security policy

Do not open a public issue for a suspected vulnerability or leaked credential. Until a dedicated security inbox is published, contact the repository owner privately through GitHub security advisories.

Supported versions will be listed after the first release. The current unreleased alpha receives best-effort fixes only.

Never submit real API keys, card data, OTPs, identity documents, or unredacted provider payloads. This project uses hosted checkout and is not designed to process raw card details. See the [threat model](docs/security/threat-model.md).
