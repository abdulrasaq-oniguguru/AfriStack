## Verified commands

The foundation has been run locally with `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`, and Docker Compose. The provider-specific live evidence is recorded only for Paystack, not Flutterwave.

## Release blockers

1. Add minimal working Node, Express, Next.js server-side, and Django gateway examples.
2. Add a clean Docker mock smoke test to CI. The CI branch trigger is corrected.
3. Expand webhook/idempotency concurrency and redaction tests.
4. Add certification scripts which run only when provider credentials are explicitly supplied.
5. Add versioned database migrations or explicitly document the startup-schema strategy and its upgrade limitations.
6. Complete Flutterwave sandbox certification before describing it as certified.
7. Audit package publish metadata and `npm pack --dry-run` contents before any npm release.

## Non-blockers deliberately deferred

M-Pesa, MTN MoMo, identity, offline sync, AI recommendations, dashboards, and billing remain out of scope until the listed release blockers are resolved.

## Golden quickstart evidence

Verified on 2026-10-04 against a freshly rebuilt local mock gateway:

```sh
docker compose --progress=quiet build gateway
PAYMENT_PROVIDERS=mock docker compose up -d --force-recreate gateway
pnpm quickstart
```

The command completed gateway health, mock payment creation, verification, signed webhook acceptance, canonical `payment.succeeded` normalization, and duplicate webhook rejection. It requires no provider account or credential.
